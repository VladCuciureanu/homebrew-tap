# Betty Homebrew tap

Homebrew formulas for [Betty](https://github.com/VladCuciureanu/Betty), a
cross-platform Bluetooth command-line tool.

```console
brew tap vladcuciureanu/tap
brew install betty-bluetooth       # bt
brew install betty-apple-audio     # optional AirPods and Beats driver
brew install betty-sony            # optional Sony headphones driver
```

The formulas are rendered from the templates in Betty's
[`packaging/homebrew`](https://github.com/VladCuciureanu/Betty/tree/main/packaging/homebrew)
for each tagged release. There are none yet: the first release adds them.
